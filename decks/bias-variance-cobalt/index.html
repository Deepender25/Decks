What is Bias? When the Model is Too Simple

UNDERFITTING SIMULATOR
"Bias is the error from overly simplistic assumptions. The algorithm systematically misses the true relationship between features and targets."
• Inflexible Hypothesis: Forcing a linear line through non-linear physical phenomena.
• High Training Error: Fails to achieve high accuracy even on the data used to train it.
• Real-World Example: Predicting house price using only square footage while ignoring location, age, and schools.
RIGID LINEAR FIT ON QUADRATIC MANIFOLD
TRAIN LOSS: 38.4% (HIGH)
TEST LOSS: 41.2% (HIGH)
DIAGNOSIS: UNDERFITTING

What is Variance? When the Model is Too Sensitive

OVERFITTING SIMULATOR
"Variance is the error caused by sensitivity to small fluctuations. The model memorizes training noise rather than discovering general laws."
• Over-Parametrization: Too many degrees of freedom, parameters, or tree depth.
• The Generalization Trap: Near 100% training accuracy but catastrophic failure on new data.
• High Instability: Retraining on a slightly different subset produces completely different predictions.
15-DEGREE POLYNOMIAL OVERFIT
TRAIN LOSS: 1.2% (PERFECT)
TEST LOSS: 64.8% (DISASTER)
DIAGNOSIS: OVERFITTING

How Do We Balance Bias & Variance?

PRACTICAL BLUEPRINTS
PILLAR 01 // ESTIMATION

Cross-Validation

Evaluate model stability across $K$ independent splits to estimate true test error before deployment.

ROTATING VALIDATION SPLITS (FOLD 1)
PILLAR 02 // CONSTRAINT

Regularization

Penalize excessively large weight coefficients to constrain hypothesis space and suppress variance.

L1 (Lasso): Loss + λΣ|w|
L2 (Ridge): Loss + λΣw²
PILLAR 03 // ARCHITECTURE

Structural Pruning

Enforce hard upper limits on model depth, early stopping epochs, and minimum samples per leaf.

• Max Tree Depth: 4–6
• Dropout Rate: 0.2–0.5

STUDENT 3

The ML Practitioner's Control Toolkit

ACTIONABLE METHODS
METHOD 01 // SHRINKAGE

L1 / L2 Penalty Adjustment (λ)

Tuning hyperparameter λ controls the tradeoff directly. Higher λ drives variance down while tolerating slightly higher bias.

METHOD 02 // ENSEMBLE LEARNING

Bagging vs. Boosting

Bagging (Random Forest) reduces variance by averaging diverse trees. Boosting (XGBoost) reduces bias sequentially.

METHOD 03 // EARLY STOPPING

Validation-Based Halting

Halt neural network training the exact epoch validation loss begins climbing, even if training loss continues plummeting.

METHOD 04 // DATA EXPANSION

Gather More Training Data

More diverse training examples directly shrinks variance without increasing bias — the only free lunch in statistical learning.

SUMMARY • Q&A
THE FUNDAMENTAL LAW OF MACHINE LEARNING
"The ultimate objective of machine learning is never to achieve 100% training accuracy. It is to find the optimal complexity that generalizes accurately to unseen future data."
1. HIGH BIAS

Model is too rigid. Fix by adding features, relaxing constraints, or increasing capacity.

2. HIGH VARIANCE

Model is over-sensitive. Fix with cross-validation, regularization, and gathering more data.

☆ 3. THE SWEET SPOT

The empirical balance that minimizes total test loss on real-world unseen distributions.
