ACT 1 : FOUNDATIONAL THEORY STUDENT 1 (LEAD)

TOTAL EXPECTED ERROR DECOMPOSITION

Every regression error breaks down into three mathematically distinct, independent components.

E[(y - ŷ)²] = [Bias(ŷ)]² + Var(ŷ) + σ² (Noise)
TERM 1

Bias² (Underfitting)

Error from erroneous assumptions. A linear model assuming a curve is straight will always be systematically off.

TERM 2

Variance (Overfitting)

Error from sensitivity to fluctuations in training data. The model fits specific noise quirks instead of the true signal.

TERM 3

Irreducible Noise (σ²)

Inherent measurement error in the real world. No algorithm, regardless of complexity, can ever beat this floor.

ACT 1 : EXTREME 1 STUDENT 1 : HIGH BIAS

HIGH BIAS: THE OVERSIMPLIFIED MODEL

Forcing a rigid straight line onto quadratic reality.

HIGH TRAINING ERROR // HIGH TEST ERROR // HIGH GAP TO REALITY

Diagnosis: Underfitting

The model lacks expressiveness. Even with 10,000,000 training samples, a linear model will never capture the parabolic curve.

Symptoms & Remedies:

  • High Training Loss (Model can't even fit seen data)
  • High Validation Loss (Equally poor generalization)
  • Remedy: Add polynomial features, increase model capacity, reduce regularization.
ACT 1 : EXTREME 2 STUDENT 1 : HIGH VARIANCE

HIGH VARIANCE: THE HYPER-SENSITIVE MODEL

Memorizing noise and wild oscillations between points.

TRAIN ERROR ≈ 0.00 // TEST ERROR EXPLODING TO ∞

Diagnosis: Overfitting

The model fits every noise fluctuation. If one data point shifts by 1%, the entire polynomial swings wildly.

Symptoms & Remedies:

  • Near-zero training loss, terrible test loss
  • Massive gap between cross-validation folds
  • Remedy: Regularization (L1/L2), gather more data, prune decision trees, dropout.

ACT 2 : THE CORE TRADEOFF STUDENT 2 (LEAD)

WHY CANNOT WE HAVE ZERO BIAS & ZERO VARIANCE?

The fundamental law of statistical learning: finite data guarantees tension.

COMPLEXITY SPECTRUM

The Seesaw Mechanism

As model complexity increases, the model gains capacity to fit intricate boundaries, which strictly decreases Bias.

However, higher capacity enables the model to memorize sampling noise, which strictly increases Variance.

MATHEMATICAL REALITY

The Total Error Curve

Total Error is the sum of a monotonically decreasing function (Bias²) and a monotonically increasing function (Variance).

Therefore, Total Error MUST be U-shaped, with a single global minimum at an optimal model complexity!

ACT 2 : OPTIMAL POINT STUDENT 2 : U-CURVE

THE U-CURVE: LOCATING THE SWEET SPOT

Interactive Complexity Inspector. Click a zone to inspect error dynamics.

ZONE 2 : BALANCED GENERALIZATION

The Optimal Complexity Zone

Here, the sum of Bias² and Variance is minimized. The model captures the true underlying pattern (quadratic curve) without fitting the random noise perturbations.

• BIAS ERROR: LOW (Accurate structure)
• VARIANCE ERROR: LOW (Stable predictions)
• GENERALIZATION: MAXIMUM
ACT 3 : PRACTICAL SOLUTIONS STUDENT 3 : REGULARIZATION

CONTROL TECHNIQUE 1: REGULARIZATION (L1 & L2)

Penalizing model complexity to constrain variance.

L2 REGULARIZATION

Ridge Regression (L2)

Loss = MSE + λ ∑ wᵢ²

Shrinks all weights smoothly toward zero without eliminating them completely. Handles multicollinearity and keeps weights small and stable.

L1 REGULARIZATION

Lasso Regression (L1)

Loss = MSE + λ ∑ |wᵢ|

Drives unimportant feature weights exactly to zero. Functions as built-in automatic feature selection for high-dimensional data.

Why It Works

Every single data sample gets used for validation exactly once. By averaging error across all K folds:

CV_Error = (1/K) ∑ Error(Fold_k)

Golden Rule:

Never tune hyperparameters on test data. Use Cross-Validation on training data to locate the U-Curve minimum, then evaluate test data once.

Key takeaways from our 3-person presentation.

Recognize The Extremes
