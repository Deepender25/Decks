HOW REINFORCEMENT LEARNING AGENTS OBSERVE

In Deep Reinforcement Learning, an autonomous agent interacts iteratively with its operational environment via sensor telemetry.

"The agent observes state s through sensors, passes it through deep neural layers, and synthesizes motor action a."

PHYSICAL ROBOT SCENARIO

Imagine a mobile robot navigating an unfamiliar room. Its optical cameras, LiDAR, and ultrasonic sensors continuously measure proximity to walls and obstacles to decide whether to accelerate, steer, or brake.

HARDWARE DILEMMA // SENSOR UNCERTAINTY

WHY REAL-WORLD SENSORS ARE NEVER PERFECT

In pure software simulations, numbers are mathematically pristine. In the physical realm, physical sensors are plagued by noise and tolerances.

"A sensor might report an obstacle at 5.0 meters, while the true physical distance is 5.2 meters. This discrepancy breaks fragile policies."

IDEAL SIMULATION

Exact floating-point measurements with zero variance ($d = 5.000\text{m}$).

PHYSICAL REALITY

Optical lens flare, ultrasonic echo, encoder slip, and thermal drift ($d = 5.230\text{m}$).

FORMAL DEFINITION // MATHEMATICAL MODEL

WHAT IS INPUT NOISE?

Input noise injection is the practice of adding controlled stochastic variations directly into sensory observations before passing them to the policy network.

"We slightly perturb the sensory state given to the agent so that it learns to make sound decisions under imperfect information."

NUMERICAL INSTANCE

Suppose the true distance is $10.0\text{ m}$. We add noise $\epsilon = +0.2\text{ m}$, providing $10.2\text{ m}$ to the network. The value remains within the operational neighborhood but prevents exact memorization.

CANONICAL FORMULATION EQUATION 01
STATE PERTURBATION EQUATION
s' = s + ε
where ε ~ N(0, σ² I) or ε ~ U(-δ, +δ)
Symbol Formal Name Operational Meaning
s True State Vector Actual ground-truth physical observation
ε Stochastic Perturbation Random noise drawn from Gaussian/Uniform kernel
s' Noisy Input State Perturbed observation ingested by neural layers
THEORETICAL MECHANISM // POLICY REGULARIZATION

WHY INPUT NOISE CREATES ROBUST AGENTS

The primary objective is robustness and generalization. Training under noise forces the policy network to flatten its decision boundaries.

"The agent internalizes a fundamental rule: 'Even if my sensory input wobbles slightly, my strategic action must remain steadfast.'"

POLICY SMOOTHING

Prevents the neural network from memorizing sharp, high-frequency artifacts in training observations.

SIM-TO-REAL TRANSFER

Physical hardware noise falls entirely within the synthetic noise envelope experienced in simulation.

INDUSTRY APPLICATIONS // DEPLOYED ROBOTICS

WHERE INPUT NOISE IS MISSION CRITICAL

01. INDUSTRIAL & MOBILE ROBOTICS ROBOTICS

Robots rely on physical LiDAR, optical cameras, and joint encoders. Input noise prevents erratic motor tremors caused by mechanical vibrations and sensor calibration tolerances.

Mitigates: Wheel slip, LiDAR jitter, optical glare.
02. AUTONOMOUS VEHICLES AUTOMOTIVE

Self-driving perception fuses GPS, radar, and camera telemetry. Input noise ensures navigation trajectories remain stable when GPS drifts in urban canyons or heavy rainfall.

Mitigates: Rain scatter, GPS multipath, sensor latency.
03. DRONES & UAVS AEROSPACE

UAV flight controllers face sudden wind turbulence and barometric altitude fluctuations. Input noise simulates these turbulent disturbances during simulation flight training.

Mitigates: Barometer drift, wind gusts, IMU tilt errors.
04. SIM2REAL TRANSFER & GAMES SIMULATION

Prevents deep learning agents from "cheating" by exploiting simulator-specific physics glitches or memorizing exact pixel configurations in visual environments.

Mitigates: Simulator memorization & reward hacking.

CRUCIAL DISTINCTION: INPUT VS. ACTION NOISE

INPUT NOISE (OBSERVATION)

"Input noise changes what the agent SEES."

ACTION NOISE (ACTUATION)

"Action noise changes what the agent DOES."

Injection Point Observation Space S (Input Layer) Action Space A (Output Layer)

STRATEGIC SYNTHESIS // BEST PRACTICES & TRADEOFFS

BALANCING PERTURBATION: THE SWEET SPOT

Input noise is powerful, but must be calibrated to match physical sensor tolerances.

THE GOLDEN RULE OF CALIBRATION RULE
σ_noise ≈ σ_hardware_tolerance

Excessive noise ($\sigma \gg \text{Signal}$) obscures informative gradients and produces degenerate policies. Calibrate to expected real-world sensor error.

KEY BENEFITS

Zero-shot Sim2Real, regularized neural weights, resilience to hardware degradation.

KEY LIMITATION

Over-noising leads to learned hesitation and sub-optimal asymptotic return.

SEMINAR CONCLUSION & ACKNOWLEDGMENTS FINAL TAKEAWAY
"NOISE IS NOT AN ERROR—IT IS THE CRUCIBLE OF ROBUST INTELLIGENCE."

By exposing deep reinforcement learning agents to stochastic uncertainty during simulation, we build autonomous systems that survive and thrive in the unpredictable physical world.
